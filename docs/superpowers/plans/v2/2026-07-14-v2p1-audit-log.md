# V2-P1 — Audit Log Persistence + V2 Harness Flip Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Persist audit events to the append-only `cms_audit_log` table behind the existing `audit.Recorder` interface (call sites untouched — BR-AUDIT-2/3), expose an admin audit browser (UAC-2.4 audit half), and flip the trace harness from V1 to V2 mode.

**Architecture:** A `Fanout` sink wraps the V1 `slog` sink and a new DB sink, so `Recorder.Emit` call sites never change. The DB sink inserts synchronously with a 2 s timeout on the shared pool; failure degrades to an error log — the `slog` line is the durable fallback. The admin API reads with keyset cursors on `(at, id)` descending. `scripts/trace.sh` drops its V2-tag exemption and the waiver file is seeded with exactly `BR-LIFE-9`.

**Tech Stack:** Go 1.25, pgx/v5, sqlc, Svelte 5 runes, Playwright.

```go
package audit

// Fanout delivers each event to every sink; the first error is returned so
// Recorder.Emit logs it, after all sinks have been attempted. Audit delivery
// is telemetry: one sink failing must not starve the others (BR-AUDIT-2).
func Fanout(sinks ...Sink) Sink { return fanout(sinks) }

type fanout []Sink

func (f fanout) Write(e Event) error {
	var first error
	for _, s := range f {
		if err := s.Write(e); err != nil && first == nil {
			first = err
		}
	}
	return first
}
```

`internal/audit/dbsink.go`:

```go
package audit

import (
	"context"
	"log/slog"
	"time"

	"github.com/codebabbler/golang-cms/internal/store"
	"github.com/google/uuid"
	"github.com/jackc/pgx/v5/pgtype"
)

const dbSinkTimeout = 2 * time.Second // spec §D1: synchronous, bounded, never blocks the request longer

type dbSink struct {
	q   *store.Queries
	log *slog.Logger
}

// NewDBSink persists events to cms_audit_log (BR-AUDIT-2). Insert failure is
// returned to the Recorder (which logs it); the slog sink in the fanout is the
// durable fallback — the originating mutation never fails on audit I/O.
func NewDBSink(q *store.Queries, log *slog.Logger) Sink { return &dbSink{q: q, log: log} }

func (s *dbSink) Write(e Event) error {
	ctx, cancel := context.WithTimeout(context.Background(), dbSinkTimeout)
	defer cancel()

	requestID, _ := e.Detail["request_id"].(string)
	detail := make(map[string]any, len(e.Detail))
	for k, v := range e.Detail {
		if k != "request_id" {
			detail[k] = v
		}
	}
	var actorID pgtype.UUID
	if e.Actor.ID != uuid.Nil {
		actorID = pgtype.UUID{Bytes: e.Actor.ID, Valid: true}
	}
	return s.q.InsertAuditEvent(ctx, store.InsertAuditEventParams{
		RequestID: pgtype.Text{String: requestID, Valid: requestID != ""},
		ActorKind: string(e.Actor.Kind),
		ActorID:   actorID,
		Action:    e.Action,
		Entity:    string(e.Entity),
		Detail:    mustJSON(detail), // marshal helper; empty map → '{}'
		At:        pgtype.Timestamptz{Time: e.At, Valid: true},
	})
}
```

(`mustJSON` is a five-line package-private `json.Marshal` wrapper returning `[]byte`; adjust param types mechanically to what `make generate` produced.) Wire in `internal/app/app.go`: replace `audit.NewRecorder(audit.NewSlogSink(log), log)` with the fanout construction from the Interfaces block — this is the only construction-site change; **no `Emit` call site changes anywhere** (BR-AUDIT-2).

## Self-Review Notes (execution-time attention)

- **Fanout error contract:** `Fanout` returns the first error after attempting all sinks; `Recorder.Emit` logs it once as `audit sink write failed`. The spec's example message `audit db write failed` is satisfied by that line naming the failing sink's error — if reviewers want the literal message, log inside `dbSink.Write` instead and return nil; either satisfies §D1's degradation contract. Flagged as an interpretation decision.
- **Cursor codec reuse:** widening `internal/query`'s UUID-typed cursor for a bigint id was rejected to keep BR-SCHEMA-3's surface untouched; the handler-local codec duplicates ~15 lines deliberately.
- **`request_id` promotion** out of `detail` into its own column mirrors the slog sink's field promotion — same event, two projections.
- **System actor** (`actor_kind='system'`) intentionally absent here: no machine-initiated mutations exist until V2-P2, which adds `access.KindSystem` (spec §D1 flag).
