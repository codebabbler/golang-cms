## Global Constraints

- Argon2id parameters pinned: **64 MiB memory, 3 iterations, parallelism 2**, per-hash 16-byte salts, 32-byte keys (BR-AUTH-3). Semaphore cap `min(4, runtime.NumCPU())`; waiters time out after **2 s** → `429 rate_limited`.
- Password policy is length-only: **≥ 10 chars admins**, ≥ 8 end users (05 §1).
- Session cookie exactly: `cms_session=<token>; HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=604800` (BR-AUTH-1). Session ID and CSRF token both rotate on every successful login.
- Only hashes at rest: sessions/CSRF via `sha256` (BR-AUTH-2). Session tokens are 256-bit random; no signing; `CMS_MASTER_SECRET` plays no role in sessions.
- Expiry: **7 days idle, 30 days absolute**; destructive ops require re-auth within **4 hours** (BR-AUTH-5); cookie re-issues with fresh `Max-Age` once **24 h** have passed since last set, never past the 30-day absolute bound.
- Login rate limits BEFORE Argon2id: **10/15 min per email, 30/15 min per IP** (BR-AUTH-6). Uniform `401 unauthorized` for bad email or bad password; always exactly one Argon2id verification even for unknown emails (05 §5).
- Setup/recovery tokens: 256-bit, logged **once at warn regardless of `CMS_LOG_LEVEL`**, in-memory only, die on use / 30 min / process exit (BR-AUTH-11/12). Never log any other token or cookie value (CLAUDE.md hard rule 6).
- Client IP per 05 §5: trusted peer (loopback / RFC1918 / `CMS_TRUSTED_PROXY_CIDRS`) → rightmost untrusted `X-Forwarded-For` entry; untrusted peer → socket address, XFF ignored.
- Rate-limit state: in-process, **bounded LRU, fixed entry cap 65,536** (compiled constant; BR-RUNTIME-4 names no number — this is the implementation's pick, documented in code).
- Role lattice: `viewer < contributor < editor < admin < super_admin` (12-access-rules §1).
- Error responses only via `httpapi.WriteError`; codes from the closed nine-code registry (BR-API-3).
- Test naming: `TestBR_XXX_N_...` / `t.Run("BR-XXX-N ...")`. Integration tests `//go:build integration`, run via `make test`.
- Commits: plain messages, no Co-Authored-By. Branch: `main` (project convention, user-authorized).
- Waiver shrink this phase: remove `BR-AUTH-1 2 3 4 5 6 11 12` and `BR-RUNTIME-4` from `docs/trace-waivers.txt`.

```go
// Package auth owns credentials, sessions, and the bootstrap/recovery tokens
// (05-auth-security.md). Nothing here logs token or password material.
package auth

import (
	"context"
	"crypto/rand"
	"crypto/subtle"
	"encoding/base64"
	"errors"
	"fmt"
	"runtime"
	"strings"
	"time"

	"golang.org/x/crypto/argon2"
)

// Pinned parameters (BR-AUTH-3): 64 MiB, 3 iterations, parallelism 2.
const (
	argonMemoryKiB = 64 * 1024
	argonTime      = 3
	argonThreads   = 2
	saltLen        = 16
	keyLen         = 32
	hashWaitBound  = 2 * time.Second
)

// ErrHashBusy: the admission semaphore stayed saturated past the wait bound.
// Handlers translate it to 429 rate_limited — hashing memory stays bounded
// at ~256 MiB regardless of request volume (BR-AUTH-3).
var ErrHashBusy = errors.New("password hashing at capacity")

type Hasher struct {
	slots chan struct{}
	wait  time.Duration
}

func NewHasher() *Hasher {
	return newHasherWith(min(4, runtime.NumCPU()), hashWaitBound)
}

func newHasherWith(capacity int, wait time.Duration) *Hasher {
	return &Hasher{slots: make(chan struct{}, capacity), wait: wait}
}

func (h *Hasher) withSlot(ctx context.Context, f func()) error {
	t := time.NewTimer(h.wait)
	defer t.Stop()
	select {
	case h.slots <- struct{}{}:
		defer func() { <-h.slots }()
		f()
		return nil
	case <-t.C:
		return ErrHashBusy
	case <-ctx.Done():
		return ctx.Err()
	}
}

func (h *Hasher) Hash(ctx context.Context, password string) (string, error) {
	salt := make([]byte, saltLen)
	if _, err := rand.Read(salt); err != nil {
		return "", err
	}
	var key []byte
	if err := h.withSlot(ctx, func() {
		key = argon2.IDKey([]byte(password), salt, argonTime, argonMemoryKiB, argonThreads, keyLen)
	}); err != nil {
		return "", err
	}
	b64 := base64.RawStdEncoding.EncodeToString
	return fmt.Sprintf("$argon2id$v=19$m=%d,t=%d,p=%d$%s$%s",
		argonMemoryKiB, argonTime, argonThreads, b64(salt), b64(key)), nil
}

func (h *Hasher) Verify(ctx context.Context, password, phc string) (bool, error) {
	parts := strings.Split(phc, "$")
	if len(parts) != 6 || parts[1] != "argon2id" {
		return false, fmt.Errorf("malformed password hash")
	}
	var m uint32
	var t, p uint8
	if _, err := fmt.Sscanf(parts[3], "m=%d,t=%d,p=%d", &m, &t, &p); err != nil {
		return false, fmt.Errorf("malformed hash parameters")
	}
	salt, err := base64.RawStdEncoding.DecodeString(parts[4])
	if err != nil {
		return false, err
	}
	want, err := base64.RawStdEncoding.DecodeString(parts[5])
	if err != nil {
		return false, err
	}
	var got []byte
	if err := h.withSlot(ctx, func() {
		got = argon2.IDKey([]byte(password), salt, uint32(t), m, p, uint32(len(want)))
	}); err != nil {
		return false, err
	}
	return subtle.ConstantTimeCompare(got, want) == 1, nil
}

// DummyHash backs the uniform-timing rule of 05 §5: login and register always
// perform one verification, even against an unknown email.
var DummyHash = func() string {
	h := newHasherWith(1, time.Minute)
	phc, err := h.Hash(context.Background(), "dummy-timing-equalizer")
	if err != nil {
		panic(err)
	}
	return phc
}()
```
